How It Works

AI-Powered Handwriting Recognition

Understand the technology behind NeuroScript

01
✏️

Draw or Upload

Draw on the canvas with mouse/touch, or upload an image (JPG, PNG, BMP, WEBP) or a PDF — multi-page PDFs are fully supported.

02
🖼️

Preprocessing

The image/PDF page is upscaled 2×, contrast-boosted, and cleaned — giving the AI model much sharper input for higher accuracy recognition.

03
🧠

Tesseract LSTM Model

Uses Tesseract.js v5 — Google's LSTM (Long Short-Term Memory) neural network OCR model, running entirely in your browser via WebAssembly. No data leaves your device.

04
📊

Confidence Scoring

Each result has a confidence score (0–100%). The LSTM model outputs probability for each character match — higher = more certain.

💡 Tips for Best Results

  • ✓ Write characters clearly and large on the canvas
  • ✓ Use consistent stroke thickness
  • ✓ Ensure good contrast in uploaded images or PDFs
  • ✓ Try "Word/Text" mode for multiple characters
  • ✓ Dark background with white ink works best
  • ✓ For PDFs, use the page navigator to scan each page
  • ✓ Click "All Pages" to recognize an entire PDF at once

⚙️ Technology Stack & AI Model

🧠
AI Model: Tesseract.js v5 — LSTM Neural Network

Tesseract was originally created by HP Labs and is now open-source, maintained by Google. The v5 engine uses a Long Short-Term Memory (LSTM) recurrent neural network — a type of deep learning model — trained on millions of text samples. It recognises handwritten and printed text in 100+ languages. This app uses the English (eng) model, configured with LSTM-only mode for maximum accuracy on handwriting.
